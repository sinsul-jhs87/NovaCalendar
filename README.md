# NovaCalendar (Tauri 2) 1.0

윈도우 11 바탕화면에 붙는 위젯 캘린더. 일정 등록 · 일/주/월 보기 · 알림 · 백업 · 구글/네이버(CalDAV)/ICS 동기화가 들어 있습니다.
테마 10종(색·배경 그림·레이아웃이 모두 다름)이 들어 있습니다.

> **미리 빌드된 설치 파일**: `NovaCalendar-Setup-1.12.2.exe`는 리눅스에서 MinGW(GNU) 방식으로 크로스 컴파일해 만든 것입니다. `build.bat`/`build_installer.bat`은 윈도우의 MSVC 방식이라 결과물 구성이 조금 다릅니다(설치 파일에는 `WebView2Loader.dll`이 함께 들어 있고, 코드 서명은 없음). 설치 파일은 관리자 권한 없이 현재 사용자에게 설치됩니다.

## 1. 실행

압축을 풀고 **`build.bat`을 더블클릭**하세요. 필요한 도구(C++ 빌드 도구, Rust, Node.js) 중 없는 것만 `winget`으로 설치하고, 컴파일한 뒤 `WidgetCalendar.exe`를 만들어 바로 실행합니다.

- 처음에는 도구 설치 때문에 30분 이상 걸릴 수 있습니다. 중간에 관리자 권한 창이 뜨면 [예]를 누르세요.
- 이미 도구가 있으면 컴파일(10~15분)만 합니다. 두 번째부터는 훨씬 빠릅니다.
- 만들어진 `WidgetCalendar.exe`는 단독 실행 파일입니다. 다른 폴더로 옮겨도, 다른 PC에 복사해도 동작합니다(받는 PC에 개발 도구는 필요 없음).
- 다음부터는 `start.bat` 또는 `WidgetCalendar.exe`만 실행하면 됩니다. 이미 실행 중이면 새로 띄우지 않고 기존 위젯을 보여 줍니다.
- 코드를 고친 뒤 다시 만들려면 `build.bat`. 실행 중인 위젯은 자동으로 종료하고 교체합니다.
- **설치 파일(Setup.exe)** 이 필요하면 `build_installer.bat`. 관리자 권한 없이 현재 사용자에게 설치됩니다.
- 도구 설치 직후 오류가 나면 창을 닫고 `build.bat`을 한 번 더 실행하세요. 이어서 진행됩니다.
- 코드 서명이 없어서 처음 실행할 때 SmartScreen이 경고하면 [추가 정보 → 실행]을 누르세요.

## 코드 서명 (회사 인증서)

설치 파일과 exe에 회사 인증서로 서명하면 윈도우가 "알 수 없는 게시자" 대신 회사 이름을 표시합니다.

- **윈도우 PC에서**: `sign_installer.bat 인증서.pfx` (파일을 생략하면 `WidgetCalendar.exe`와 `build_installer.bat`이 만든 설치 파일을 찾아 서명). 암호는 입력하거나 환경 변수 `SIGN_PASS`로 전달합니다. `signtool.exe`(Visual Studio Build Tools에 포함)가 필요합니다. 이 방식은 **설치 파일과 exe 겉면**에 서명하며, 설치 파일 안에 든 프로그램 exe까지 서명하려면 Tauri 설정의 `bundle.windows.signCommand`를 쓰세요.
- **인증서 종류에 따른 차이**
  - 인증기관(CA)에서 발급받은 코드 서명 인증서(OV/EV): 모든 PC에서 게시자 이름이 표시됩니다. SmartScreen 경고는 OV는 평판이 쌓일 때까지, EV는 처음부터 줄어듭니다.
  - 회사 자체(사내) 인증서: 인증서를 등록한 PC에서만 신뢰됩니다. 나머지 PC에서는 경고가 그대로 나옵니다. 인증서를 새로 만들면 모든 PC에 다시 등록해야 하므로, 이미 쓰는 사내 인증서가 있다면 그것을 계속 쓰세요.
- 인증서 파일(`.pfx`)에는 개인 키가 들어 있습니다. 회사 안에서만 보관하고, 저장소에 올리거나 외부에 공유하지 마세요.

## 2. 사용법

위쪽 가운데 [일 주 월]로 보기를 바꾸고, 오른쪽의 **메뉴(☰)** 에서 나머지 기능을 씁니다. (테마에 따라 막대 위치는 달라지지만 구성은 같습니다.)

| 동작 | 방법 |
|---|---|
| 메뉴 | ☰ 버튼 → 위치·크기 바꾸기 / 테마 / 설정 / 트레이로 숨기기 / 종료 |
| 위젯 이동·크기 조절 | 평소에는 **고정**되어 움직이지 않습니다. 메뉴 → "위치·크기 바꾸기"를 켜면 아무 곳이나 끌어서 옮기고, 가장자리를 끌어 크기를 바꿀 수 있습니다. [완료 · 고정하기]를 누르면 위치를 저장하고 다시 고정합니다. |
| 테마 | 메뉴 → 테마. 누르는 즉시 적용되고 저장됩니다. |
| 설정 | 메뉴 → 설정. 값을 바꾼 뒤 **[저장]** 을 눌러야 적용됩니다. [취소]나 창 닫기는 저장하지 않습니다. (바꾸는 동안 투명도·보기 방식은 위젯에 미리 보입니다) |
| 오늘로 이동 | 제목(월 이름) 또는 [오늘] 클릭 |
| 날짜 상세 창 | 월 보기의 날짜 칸, 주·일 보기의 날짜 머리줄을 한 번 클릭 |
| 여러 날 일정 등록 | 시작 날짜에서 끝 날짜까지 드래그 → 등록 창 |
| 시간 일정 등록 | 주·일 보기에서 빈 시간대를 클릭(30분 단위) |
| 넘친 일정 보기 | 칸 아래쪽 흐려진 부분에 마우스를 올리면 자동으로 내려가고, 벗어나면 되돌아감 |
| 숨기기 / 종료 | 메뉴 → 트레이로 숨기기(알림은 계속 동작) / 종료. 가려진 위젯은 트레이 아이콘을 왼쪽 클릭하면 5초간 앞으로 나옵니다. |

월별 보기 방식(설정): **현재 달 기준** / **오늘 기준 위아래 2주**(오늘이 있는 주의 앞뒤 2주, 5주).
위젯의 투명도(설정)는 배경색과 테마 배경 그림에 함께 적용됩니다. 글자 뒤에는 테마 배경색 후광이 깔려 있어, 투명하게 해도 글자가 바탕화면에 묻히지 않습니다.

## 3-2. 공휴일 · 기념일 · 음력 · 오늘 표시

설정 → "달력 표시"에서 **공휴일 / 기념일·24절기 / 음력**을 각각 켜고 끌 수 있습니다. (저장하기 전에는 위젯에 미리 보이기만 합니다.)

- **공휴일**: 신정, 설날(연휴), 삼일절, 어린이날, 부처님오신날, 현충일, 광복절, 추석(연휴), 개천절, 한글날, 성탄절, **대체공휴일**(설·추석·어린이날 2014년, 삼일절·광복절·개천절·한글날 2021년, 부처님오신날·성탄절 2023년 시행 기준), 선거일. 빨간 굵은 글씨로 표시되고 날짜 숫자도 빨개집니다.
- **기념일·절기**: 어버이날, 스승의 날, 성년의 날, 부부의 날, 식목일, 제헌절, 국군의 날, 노동절, 밸런타인·화이트데이, 크리스마스 이브, 정월대보름, 단오, 칠석, 백중, 중양절, 섣달그믐, **초복·중복·말복**, 한식, **24절기**.
- **음력**: 날짜 옆에 `9.18`처럼 표시합니다. **윤달은 `윤6.17`** 처럼 "윤"이 붙고(기울임), 음력 초하루는 강조됩니다. 날짜 칸에 마우스를 올리면 "음력 윤6월 17일"처럼 길게 나옵니다. 상세 창 제목 아래에도 음력과 공휴일·기념일 이름이 나옵니다.
- **인터넷이 필요 없습니다.** 음력(1900-01-31 ~ 2050-12-31)과 24절기 표를 앱에 내장했습니다. 음력 표는 한국 음력 라이브러리와 55,000일 이상을 전수 비교했고, 24절기는 천문 계산으로 만든 표를 별도 천문 라이브러리와 교차 검증했습니다(공식 시각과 1분 이내).
- **임시공휴일**처럼 정부가 새로 지정하는 날은 미리 알 수 없습니다. 설정의 [설정 폴더 열기]로 열리는 폴더의 `holidays_custom.json`에 적어 두면 표시됩니다. `"off": false`를 붙이면 쉬는 날이 아닌 기념일로 표시합니다. 앱을 다시 켜거나 설정을 저장하면 반영됩니다.
  ```json
  [
    {"date": "2026-12-31", "name": "임시공휴일"},
    {"date": "2026-11-11", "name": "우리 회사 창립기념일", "off": false}
  ]
  ```
- 내장된 선거일은 2030년 지방선거까지이고, 2028년·2030년 선거일은 법 규정으로 계산한 날짜입니다. 실제 확정일이 다르면 위 파일로 바로잡으세요.
- **오늘** 날짜는 칸 전체가 테두리와 빛으로 강조됩니다(줄 노트·표 모양에서는 띠/윤곽선). 일/주/월 버튼은 움직이는 표시와 아이콘으로 바뀌었고 테마마다 모양이 조금씩 다릅니다.

## 3-3. 글자 크기 · 글꼴 · 바탕 진하기

설정 → "글자와 바탕"에서 바꿉니다. 저장하기 전에는 위젯에 미리 보이기만 하고, [저장]을 눌러야 적용됩니다.

- **글자 크기** 80~160%: 글자와 함께 일정 줄 높이, 날짜 숫자, 헤더, 시간표(주·일 보기)의 시간 간격도 함께 커집니다. 상세 창과 알림 팝업에도 적용됩니다(설정 창 자체는 그대로).
- **글꼴**: 이 PC에 설치된 글꼴만 목록에 나옵니다(맑은 고딕, 나눔고딕, Pretendard, 바탕, 고정폭 글꼴 등). 목록에 없는 글꼴은 "직접 입력"에 이름을 적으세요. 없는 글꼴이면 기본 글꼴로 표시됩니다. 글꼴을 고르면 테마가 정한 제목용 글꼴(한지의 바탕체, 네온 시티의 고정폭)보다 고른 글꼴이 우선합니다.
- **칸·일정 바탕 진하기**: 낮출수록 날짜 칸과 일정의 바탕색이 옅어져 위젯이 한 면처럼 보입니다. 0%면 바탕 없이 글자와 선만 남습니다.
- 위젯 **투명도**를 낮추면 글자 뒤에 테마 배경색이 서서히 깔려 바탕화면 위에서도 글자가 읽히도록 합니다(불투명할 때는 보이지 않음).

## 3-4. 헤더와 "오늘 일정 패널"

- **헤더 상단 고정**: 연·월 제목, 일/주/월 버튼, 메뉴 아이콘은 모든 테마에서 위쪽에 있습니다(예전의 하단·세로 막대 형태는 없앴습니다). 메뉴는 테마와 상관없이 **메뉴 아이콘 바로 아래**에서 열립니다.
- **오늘 일정 패널 스위치**: 일부 테마에는 "오늘" 패널(오로라·세이지), "다가오는 일정" 패널(숲·콘크리트 등), 아래 "카드 줄"(벚꽃)이 있습니다. 메뉴의 [오늘 일정 패널] 스위치를 누르면 바로 보이거나 숨겨지고, 설정 → 달력 표시에서도 같은 스위치로 바꿀 수 있습니다. 패널이 없는 테마에서는 메뉴 항목이 흐리게 보이며 변화가 없습니다.
- 설정 창의 켜고 끄는 항목(자동 시작, 알림, 공휴일·기념일·음력·패널 표시, 백업)은 모두 슬라이딩 스위치입니다.
- 음력은 양력 숫자 **바로 옆**에 작게 표시됩니다(숫자가 오른쪽에 있는 테마에서는 숫자 왼쪽).

## 3-5. 연·월 바로 가기 · 날짜 팝업 · 모니터

- **연·월 바로 가기**: 위쪽 "2026년 10월 ▾" 제목을 누르면 선택창이 열립니다. 연도는 ‹ › 로 넘기거나 숫자를 직접 입력할 수 있고(1900~2100), 월 버튼을 누르면 그 연·월로 바로 이동합니다. [오늘로 이동]도 있습니다. (예전에는 제목을 누르면 오늘로 갔고, 이제는 [오늘] 버튼이 그 역할을 합니다.)
- **날짜 팝업**: 날짜 칸을 누르면 그 칸 크기에서 시작해 달력 앞으로 커지며 펼쳐집니다(시스템에서 애니메이션 줄이기를 켜 두었으면 부드럽게 나타남). 큰 날짜 숫자, 음력·공휴일, 그날의 일정 목록과 [＋ 일정 추가] 버튼이 있고, 일정을 누르면 수정·삭제, 바깥을 누르거나 Esc로 닫습니다. 여러 날을 끌어서 고르거나 주·일 보기의 빈 시간대를 누르면 곧바로 입력 폼이 펼쳐집니다. 입력 폼은 테마의 색·배경 그림·글꼴을 그대로 쓰고, 종일 항목은 슬라이딩 스위치입니다.
- 알림을 눌렀을 때 뜨는 별도 창도 같은 화면을 씁니다(위젯이 뒤에 있어도 앞에 나와야 하므로 이 경우만 별도 창입니다).
- **모니터**: 설정 창·알림 팝업·알림을 눌렀을 때의 날짜 창은 **위젯이 놓인 모니터**에 뜹니다(알림은 그 모니터의 오른쪽 위). 모니터마다 배율이 달라도 맞도록 물리 좌표로 계산합니다.

### Google 오류 안내

로그인이나 동기화가 실패하면 계정 아래에 원인과 조치 방법이 한국어로 나오고, Google이 보낸 원문이 괄호로 붙습니다. 주요 경우는 다음과 같습니다.

| 증상 | 원인 | 조치 |
|---|---|---|
| Client ID/Secret 오류(`invalid_client`) | 값이 다르거나 "데스크톱 앱" 유형이 아님 | 데스크톱 앱 유형으로 만든 값을 그대로 복사 |
| `redirect_uri_mismatch` | 웹 애플리케이션 유형으로 만듦 | 데스크톱 앱 유형으로 새로 만들기 |
| `access_denied` | 동의 화면이 "테스트"인데 로그인 계정이 테스트 사용자가 아님 | 테스트 사용자에 계정 추가 |
| Google Calendar API 사용 설정 안 됨 | 프로젝트에서 API를 켜지 않음 | API 및 서비스 → 라이브러리에서 사용 설정 |
| 캘린더 권한이 허용되지 않음 | 권한 화면에서 캘린더 항목을 체크하지 않음 | 다시 로그인하면서 체크 |
| 로그인이 만료됨(`invalid_grant`) | 테스트 상태 앱은 7일마다 만료 | 계정을 지우고 다시 로그인 |

알림을 5개 넘게 고른 일정은 Google이 거부(400 오류)하므로, Google에는 가까운 5개까지만 보내고 앱에는 모두 남깁니다.

## 3-1. 알림

일정을 등록할 때 알림 시간을 여러 개 고를 수 있습니다(정시 / 5분 / 10분 / 30분 / 1시간 / 3시간 / 1일 / 1주 전). 시간이 되면 **화면 오른쪽 위에 알림 팝업 창**이 뜹니다.

- 여러 개가 겹치면 위에서 아래로 쌓입니다(최대 5개). 10초 뒤 자동으로 닫히고, 마우스를 올려 두면 시간이 멈춥니다. 알림을 누르면 그 날짜의 상세 창이 열립니다.
- 설정에서 "윈도우 기본 알림"으로 바꿀 수도 있습니다. [알림 테스트]로 미리 볼 수 있습니다.
- 종일 일정의 알림은 **당일 오전 9시**를 기준으로 계산합니다(예: "1일 전" = 전날 오전 9시).
- 알림은 위젯(트레이)이 실행 중일 때만 울립니다. 설정에서 "윈도우를 켜면 자동으로 실행"을 켜 두세요.
- 절전 등으로 놓친 알림은 30분 안이면 늦게라도 알려주고, 같은 알림은 다시 울리지 않습니다.

## 4. 캘린더 동기화 (설정 → 캘린더 동기화)

| 종류 | 방향 | 준비물 |
|---|---|---|
| Google | 양방향 | **[Google로 로그인] 버튼 하나** (개발자가 Client ID를 앱에 한 번 내장해 둔 경우. 아래 "Google 로그인 설정" 참고) |
| 네이버 | 양방향 | 네이버 아이디 + 비밀번호(2단계 인증 시 애플리케이션 비밀번호), CalDAV |
| CalDAV | 양방향 | 서버 주소, 아이디, 비밀번호 (iCloud, Nextcloud 등) |
| ICS 구독 | 읽기 전용 | 비공개 iCal 주소(https:// 또는 webcal://) 또는 .ics 파일 경로 |

- **삼성 캘린더**는 공개 API가 없어 직접 연결할 수 없습니다. 휴대폰의 삼성 캘린더에서 Google 계정과 동기화를 켜 두고, 여기서는 Google로 연결하세요.
- **Google 연결**: 설정 → Google → [Google로 로그인]을 누르면 기본 브라우저에서 로그인 창이 열리고, "허용"을 누르면 완료됩니다. 앱에 Client ID가 내장되어 있지 않으면 직접 입력하는 폼이 대신 나옵니다(아래 설정을 한 번 해 두면 사라집니다).
- 동기화는 시작 5초 뒤, 이후 설정한 주기(기본 15분)마다, 그리고 일정을 고친 직후에 자동으로 합니다. 범위는 오늘 기준 과거 90일 ~ 미래 365일입니다.
- 일정을 새로 만들 때 등록 창의 [캘린더]에서 저장할 곳을 고릅니다("내 캘린더"는 이 PC에만 저장). 이미 만든 일정의 캘린더는 바꿀 수 없습니다.
- 반복 일정(CalDAV/ICS)은 펼쳐서 **읽기 전용**으로 보여 줍니다(빗금 무늬). 원본 반복 규칙을 망가뜨리지 않기 위해서입니다. Google의 반복 일정은 개별 일정으로 수정할 수 있습니다.
- 계정을 삭제하면 이 PC에 가져온 일정만 지워지고 서버의 일정은 그대로입니다.
- 계정 비밀번호와 토큰은 `%APPDATA%\com.widgetcalendar.app\accounts.json`에 암호화 없이 저장됩니다(내 계정 폴더 안). 공용 PC에서는 사용하지 마세요.

### Google 로그인 설정 (개발자가 한 번만)

계정을 추가하는 사람은 **API 키를 입력하지 않고** [Google로 로그인] 버튼만 누릅니다. 다만 Google은 앱마다 등록된 Client ID가 있어야 로그인을 허용하므로, 아래 등록은 **누군가 한 번은** 해야 합니다. 방법은 둘 중 하나입니다.
- 설정 → 캘린더 동기화 → Google을 눌렀을 때 나오는 "최초 1회" 화면에 Client ID/Secret을 입력(이 PC에 저장되고, 이후에는 버튼만 보입니다), 또는
- 아래 5번처럼 `google_client.json`에 넣고 다시 빌드(모든 사용자에게 처음부터 버튼만 보입니다).

[Google로 로그인] 버튼 하나로 연결되게 하려면 앱에 Client ID가 들어 있어야 합니다. 아래는 제가 아는 구글 정책 기준이며, 바뀌었을 수 있으니 콘솔의 안내도 함께 확인하세요.

1. Google Cloud Console(console.cloud.google.com)에서 프로젝트를 만들고 **Google Calendar API**를 사용 설정합니다.
2. **OAuth 동의 화면**을 설정합니다. 사용 범위에 따라 선택이 달라집니다.
   - 나 혼자 · 소수: "외부" + 테스트 사용자 등록(최대 100명). 이 상태에서는 로그인이 **7일마다 만료**되어 매주 다시 로그인해야 합니다.
   - 회사 Google Workspace 안에서만: **"내부"** — 심사도 만료도 없어 가장 깔끔합니다.
   - 불특정 다수에게 배포: "프로덕션" 게시 + 구글 앱 심사(캘린더는 민감 범위라 심사가 필요하고 몇 주 걸릴 수 있음).
3. 범위(scope)에 `https://www.googleapis.com/auth/calendar`를 추가합니다.
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기**에서 유형을 **"데스크톱 앱"** 으로 만듭니다.
5. 발급된 값을 `src-tauri/google_client.json`의 `clientId`, `clientSecret`에 넣고 `build.bat`으로 다시 빌드합니다(exe에 내장됨).
   - 다시 빌드하지 않으려면 같은 내용의 `google_client.json`을 `%APPDATA%\com.widgetcalendar.app\`에 두세요. 그 파일이 내장 값보다 우선합니다.
   - 데스크톱 앱의 Client Secret은 구글 문서상 비밀로 취급하지 않는 값이지만, exe에서 꺼낼 수 있으므로 공개 저장소에는 올리지 마세요.
   - 값이 비어 있으면 앱은 사용자가 직접 Client ID를 입력하는 폼을 보여 줍니다.

## 사내 배포와 자동 업데이트

기본 업데이트 위치는 `\\DESKTOP-2KBH0F7\NovaCalendarUpdateServer`입니다(설정에서 비워 두면 이 위치를 씀). 이 폴더에 새 설치 파일과 `latest.json` 두 개만 두면 됩니다. 새 버전마다 설치 파일과 `latest.json`을 함께 받아 이 폴더에 넣으면 됩니다.

1. 공유 폴더(예: `\\fileserver\share\NovaCalendar`)나 사내 웹 주소에 새 설치 파일(`NovaCalendar-Setup-<버전>.exe`)을 올립니다.
2. PowerShell에서 `tools\update\make-latest.ps1 -Setup "<설치 파일 경로>" -Notes "바뀐 내용"`을 실행하면 같은 폴더에 `latest.json`(버전·파일 이름·SHA-256)이 생깁니다.
3. 각 PC는 설정 → 업데이트 → **업데이트 위치**에 그 폴더(또는 주소)를 한 번 넣고 저장합니다. 켤 때와 6시간마다 확인해 새 버전이면 알림이 뜨고 위젯 메뉴에 **업데이트 설치**가 나타납니다(두 번 눌러 설치).
4. 설치 파일을 받아 SHA-256 을 확인한 뒤, 위젯을 끄고 조용히 설치하고 다시 켭니다. 해시가 다르면 설치하지 않습니다.

설치 파일에 사내 인증서로 서명하는 것은 그대로 `sign_installer.bat`로 합니다(시간 도장 포함).

## 플로우 캘린더 연결

1. 플로우의 **키 관리 페이지**에서 API 키를 발급받습니다.
2. 설정 → 캘린더 동기화 → **플로우** → API 키 입력 → **캘린더 불러오기**.
3. 가져올 캘린더를 고르고 **연결**. 일정이 읽기 전용으로 들어옵니다(위젯에서 고친 내용은 플로우에 올라가지 않음).

사용하는 API: `GET /user/calendars`(캘린더 목록), `GET /user/calendars/events`(일정 범위 조회, `startDateTime`·`endDateTime`·`cursor`·`pageSize`). 다음 날 00:00:00으로 끝나는 일정은 그 전날까지로 표시합니다.

## 바로 가기 아이콘 바꾸기

기본 아이콘은 "겹친 일정표"입니다. 설치 폴더(`%LOCALAPPDATA%\NovaCalendar\icons`)에 아이콘 3개가 들어 있습니다: `NovaCalendar-default.ico`(기본), `NovaCalendar-orbit.ico`(궤도), `NovaCalendar-fluent.ico`(플루언트 블루).

1. 바탕화면이나 시작 메뉴의 NovaCalendar 바로 가기를 마우스 오른쪽 단추로 누르고 **속성**을 엽니다. (시작 메뉴는 **파일 위치 열기** 후 바로 가기의 속성)
2. **아이콘 변경** → **찾아보기** → 위 `icons` 폴더에서 원하는 아이콘을 고르고 확인합니다.

바로 가기의 아이콘만 바뀌고, 작업 표시줄에서 실행 중인 창의 아이콘은 기본 아이콘으로 나옵니다.

## 코드 서명 시간 도장

윈도우에서 서명할 때 쓰는 `sign_installer.bat`은 시간 도장(`/tr` 시간 서버, `/td sha256`)을 붙입니다. 시간 도장이 있으면 인증서 유효기간(2036년)이 끝난 뒤에도 서명이 유효합니다. 이 저장소에 함께 드리는 설치 파일은 외부 시간 서버에 접속할 수 없는 환경에서 서명해서 시간 도장이 없습니다. 사내 PC에서 `sign_installer.bat`으로 다시 서명하면 붙습니다.

## 5. 백업

동기화 계정이 **없을 때**, 일정을 바꿀 때마다 `문서\WidgetCalendar\` 폴더에 자동 백업합니다.

- `calendar-backup.json`: 복원용 최신 백업
- `calendar.ics`: 다른 캘린더 앱으로 옮길 수 있는 표준 파일
- `backup-날짜.json`: 날짜별 사본(최근 14일)

설정 → 백업에서 [지금 백업](계정이 있어도 가능), [폴더 열기], [백업에서 복원]을 쓸 수 있습니다. 복원은 현재 일정을 지우지 않고 합치며, 같은 일정이면 더 최근에 고친 쪽을 남깁니다.

```
   ├─ lib.rs               명령어, 트레이, 창 관리, 이동 모드, 앱 시작
   ├─ store.rs             일정·설정·계정 저장 (JSON)
   ├─ reminder.rs          알림 스케줄러
   ├─ toast.rs             오른쪽 위 알림 팝업 창 관리(쌓기·정렬)
   ├─ backup.rs            문서 폴더 백업·복원
   ├─ pin.rs               Win+D 대응, 도구 창 속성
   ├─ sync/                ical.rs(파서·반복 일정), google.rs, caldav.rs, mod.rs(합치기)
   └─ ../google_client.json   Google 로그인 정보(Client ID) 내장용. 비어 있음
```
